# Vehicle Acquisition Checklist

## Before buying
- [ ] Run VIN / history checks
- [ ] Confirm title status and seller ownership
- [ ] Confirm no obvious title-brand surprise
- [ ] Estimate auction / transport / buyer fees
- [ ] Set maximum buy number before bidding
- [ ] Estimate recon before purchase
- [ ] Check comparable retail listings
- [ ] Estimate realistic days-to-sale

## On arrival
- [ ] Photograph all sides
- [ ] Photograph VIN
- [ ] Record mileage
- [ ] Check warning lights
- [ ] Test drive if safe
- [ ] Check tires / brakes / glass / lights
- [ ] Scan for diagnostic codes when appropriate
- [ ] Confirm keys / remotes
- [ ] Confirm title paperwork received

## Cost basis
Track:

`Purchase price + auction fees + transport + mechanical + body + detail + tires + keys + title/other direct costs = true cost basis`

## Pricing
- [ ] Set target retail price
- [ ] Set minimum acceptable gross
- [ ] Set markdown review date
- [ ] Publish only after recon / photos / paperwork are ready
