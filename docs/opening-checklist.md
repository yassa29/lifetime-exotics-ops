# Lifetime Exotics Opening Checklist

## Licensing and compliance

- [ ] Surety bond finalized
- [ ] Garage liability / Any Auto insurance finalized
- [ ] CPA financial statement completed
- [ ] Ownership Worksheet completed
- [ ] Garage Service Agreement signed
- [ ] Sales & Use Tax certificate reviewed/corrected if needed
- [ ] Permanent sign installed
- [ ] Salesperson licensing completed
- [ ] CORE dealer application submitted
- [ ] State inspection passed

## Building and utilities

- [ ] Electrical service restored
- [ ] Water/restroom operational
- [ ] Office cleaned and furnished
- [ ] Exterior cleaned
- [ ] Lot prepared for display inventory
- [ ] Customer parking spaces identified
- [ ] Business hours and phone posted
- [ ] Required photos taken

## Operations

- [ ] Business bank account fully ready
- [ ] Dealer management / bookkeeping process selected
- [ ] Deal-jacket checklist created
- [ ] Temp-tag / EZ Tag process ready
- [ ] Dealer plates handled
- [ ] Auction accounts opened
- [ ] Floorplan financing selected, if using
- [ ] Vehicle recon process documented
- [ ] Title / registration workflow documented
- [ ] Sales-tax filing calendar established

## Sales launch

- [ ] Google Business Profile
- [ ] Website / inventory page
- [ ] Business phone active
- [ ] Financing partners contacted
- [ ] Social media branding ready
- [ ] First inventory photos ready
