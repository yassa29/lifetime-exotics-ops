# Recon Checklist

## Safety first
- [ ] Tires safe / correct pressure
- [ ] Brakes checked
- [ ] Steering / suspension checked
- [ ] Headlights / brake lights / signals work
- [ ] Windshield / mirrors acceptable
- [ ] Seat belts work
- [ ] No major leaks
- [ ] No critical warning lights ignored

## Mechanical
- [ ] Fluids checked
- [ ] Battery / charging system checked
- [ ] HVAC checked
- [ ] Engine / transmission operation checked
- [ ] Diagnostic scan completed when needed
- [ ] Required repairs approved
- [ ] Repair invoice attached to internal vehicle record

## Cosmetic
- [ ] Exterior wash
- [ ] Interior detail
- [ ] Odor treatment if needed
- [ ] Paint / body estimate if needed
- [ ] Wheels / trim cleaned
- [ ] Photos taken after recon, not before

## Sale-ready
- [ ] Buyers Guide ready
- [ ] Keys / remotes ready
- [ ] Title paperwork ready
- [ ] Online listing completed
- [ ] Price approved
- [ ] Vehicle moved to front-line inventory
