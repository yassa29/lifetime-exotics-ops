# Vehicle Profit Calculator

Use this before buying and again after sale.

## True cost basis

`purchase price + auction fees + transport + recon + detail + keys + title/direct costs = true cost basis`

## Front-end gross

`sale price - true cost basis = front-end gross`

## Gross margin

`front-end gross / sale price × 100 = gross margin %`

## Example

- Purchase: $15,000
- Auction fees: $650
- Transport: $350
- Recon: $1,200
- Detail / keys / misc: $300
- True cost: $17,500
- Sale price: $20,995
- Front-end gross: $3,495
- Gross margin: 16.6%

- **Maximum buy:** `retail - target gross - expected non-purchase costs`

## Floorplan reality check

If the unit is floorplanned, add estimated interest / curtailment / audit / transportation fees into the unit economics before deciding whether the buy still makes sense.

## Aged-unit review

At 30 / 45 / 60 / 90 days, compare:
- Current market retail
- Current true cost
- Accrued floorplan cost
- Expected gross if sold today
- Cost of holding another 15–30 days

The goal is not to protect the original asking price. The goal is to protect cash flow and total annual gross.
