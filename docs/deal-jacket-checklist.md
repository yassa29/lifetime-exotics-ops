# Deal Jacket Checklist

Use one folder / digital record per sold vehicle.

## Vehicle
- [ ] VIN verified in every document
- [ ] Year / make / model / mileage match
- [ ] Title status verified before sale
- [ ] Dealer inventory record updated
- [ ] Odometer disclosure completed when required

## Buyer
- [ ] Buyer legal name and address match sale paperwork
- [ ] Required identification reviewed securely
- [ ] Buyer contact information recorded

## Sale documents
- [ ] Buyer's order / bill of sale
- [ ] Retail installment contract if financed
- [ ] Buyers Guide provided as required
- [ ] Odometer disclosure if required
- [ ] Title / reassignment documents completed
- [ ] Temp-tag paperwork completed when eligible
- [ ] Taxes / fees calculated and documented
- [ ] Trade-in paperwork if applicable
- [ ] Warranty / AS-IS documents completed

## Money
- [ ] Down payment received and recorded
- [ ] Funding source recorded
- [ ] Lender approval / funding confirmation if financed
- [ ] Trade payoff verified if applicable
- [ ] Deal gross recorded internally

## Closeout
- [ ] Copies provided to customer
- [ ] Title work submitted on time
- [ ] Lienholder information entered correctly
- [ ] Inventory marked sold
- [ ] Recon / acquisition costs finalized
- [ ] Sensitive documents stored only in an approved secure system, not GitHub
