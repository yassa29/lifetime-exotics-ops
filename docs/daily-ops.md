# Daily Dealership Ops

## Opening
- [ ] Walk lot and check every vehicle
- [ ] Check windows / doors / keys
- [ ] Check for leaks, damage, low tires, dead batteries
- [ ] Move priority units to best display spots
- [ ] Confirm office, restroom, lights, and internet are ready
- [ ] Review new leads / messages
- [ ] Review today's appointments
- [ ] Review title / funding / lender follow-ups

## During the day
- [ ] Log every serious lead
- [ ] Record test drives
- [ ] Keep keys controlled
- [ ] Update inventory status after every deposit / sale
- [ ] Record new recon issues immediately
- [ ] Save vendor invoices to the proper secure system
- [ ] Follow up on funded / unfunded deals

## Closing
- [ ] Lock every vehicle
- [ ] Bring keys inside
- [ ] Confirm deposits / deals are recorded
- [ ] Check building doors and windows
- [ ] Turn off nonessential equipment
- [ ] Review tomorrow's appointments
- [ ] Note vehicles that need attention first thing tomorrow

## Weekly rhythm
- Monday: aged inventory review
- Tuesday: recon / vendor follow-up
- Wednesday: lender / funding review
- Thursday: pricing / market review
- Friday: title / tax / paperwork audit
- Saturday: front-line presentation + customer focus
